# 使われ方のシナリオ

sarari を使う人の一連の操作と、そのとき起きるべきこと。単体テストが判定部分を切り出して確かめるのに対し、ここは「話して、入る」までを通して見る。

- **確かめ方**: 「自動」は E2E テスト（`scripts/e2e.sh`）で確かめる。「手」はリリース前に実機で試す。手で試すのは、そのリリースで変わった所に関係するものだけでよい
- **直すとき**: 使う人から見て何かが変わる PR では、説明書（`MANUAL.md`）と同じく、ここも直す。シナリオが消えた機能に頼っていれば消し、新しい機能で使い方が増えれば足す
- **自動にする条件**: 中心の使い方／一度壊れたことがある／前のリリースから書き直しが要らなかった。それ以外は文章のまま置く（機能が変わるとテストごと作り直しになるため）

## 自動で確かめる

`Tests/E2E/ScenarioE2ETests.swift` が 1 シナリオ 1 テストで通す。音声は `say` の読み上げ、挿入先はテスト用の小さなアプリ（`E2EHost/`）。S5 の表示は #125 で直す。

| # | シナリオ | 起きるべきこと |
|---|---|---|
| S1 | ターミナルの入力欄にカーソルを置き、録音キーを押して話し、もう一度押す | 話した内容がカーソル位置に入る。フィラー（「えー」など）は消えている |
| S2 | 短い口述を、前の挿入が終わった直後に続けて何回かする | どの回もカーソル位置に入り、終わったあとクリップボードが口述前にコピーしていた内容に戻っている（#105） |
| S3 | 録音を始めて何も話さずに止める | 何も入らない。定型文（「ご視聴ありがとうございました」など）も入らない |
| S4 | 辞書置換に登録した言い間違いを含めて話す | 置き換えたあとの語で入る |
| S5 | パスワード欄にカーソルがある状態で口述する | 入らない。クリップボードにも残さない。結果は HUD と履歴に残る |

## 手で試す

| # | シナリオ | 起きるべきこと | 実機で見る所 |
|---|---|---|---|
| S6 | Slack やブラウザの入力欄に口述し、送信する前に手で直す | カーソル位置に入り、送信はされない（改行で送られない） | 3 文ほど口述して送信されないこと。履歴の本文に改行が無いこと |
| S7 | 話し始めた場所とは別の窓に移ってから止める | 止めたときにカーソルのある場所に入る（#116） | 右⌥ で止めた場合と、HUD の停止ボタンで止めた場合の両方 |
| S8 | 100 文字を超える長さを一度に話す | 途中で切れずに全部入る。上限（10 分）で止めたときは入らず、履歴に残る | 2〜3 分口述して末尾まで入ること |
| S9 | 音楽や環境音を流しながら、または会議の通話中に口述する | 「録音中は Mac の音量を下げる」が入りのときは、開始音のあと音が消え、停止音の前に元の音量へ戻る（#133）。開始音・停止音は聞こえる。通話の音声は録音に入らない | 環境音アプリを鳴らしたまま口述し、録音中に音量を手で変えたときはその音量のまま残るか。通話中は相手の声も消えるので、通話中に使うなら切りにする |
| S10 | Bluetooth ヘッドホンをつないだまま、またはマイクを切り替えてから口述する | 録音が始まり、最後まで入る（#91・#94） | 録音していないときにつなぐ／外したあとの最初の口述。つないだまま 10 秒以上の口述 |
| S11 | Mac の起動直後、またはスリープから戻った直後に最初の口述をする | 準備ができていなければ、録音キーを押した時点で HUD に理由が出る（読み込み中・読み込みの失敗・マイク権限なし）。準備ができてからの最初の口述は入る（#123） | 30 分以上のスリープから戻った直後の1回目。録音キーが修飾キーだけの設定と、通常キーとの組み合わせの両方 |
